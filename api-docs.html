lightbulb Notas Técnicas del Backend Actual (Para Futura Organización)
  • Respuestas de Error del Middleware JWT (verificarToken): Devuelve 401 Unauthorized con { "message": "Acceso denegado. Token no proporcionado." } o { "message": "Token inválido o expirado." }.
  • Respuestas de Error del Middleware de Rol (permitirRoles): Devuelve 403 Forbidden con { "message": "No tienes permisos para realizar esta acción." }.
  • Publicación Automática de Recursos: Al ejecutar PATCH /api/tutorias/:id/finalizar, todos los enlaces guardados en tutoria.recursos y tutoria.enlaceGrabacion se insertan automáticamente en la colección Recurso bajo la escuela del profesor con la etiqueta Clase: <materia> - <tema>.
  • Modelo Tema.ts: Existe el esquema Mongoose Tema ({ nombre, materia }), aunque actualmente los temas se almacenan como texto libre (tema?: string) en SolicitudTutoria y Recurso.
